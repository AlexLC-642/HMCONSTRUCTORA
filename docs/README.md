# Documentacion del proyecto

Este directorio contiene la Etapa 0 del sistema interno de gestion de proyectos de construccion.

El objetivo de esta etapa es dejar documentadas las decisiones iniciales antes de implementar la fundacion tecnica. No se considera iniciada la Etapa 1 hasta que esta documentacion sea revisada y aprobada.

## Archivos

- `requirements.md`: requisitos consolidados.
- `architecture.md`: propuesta de arquitectura.
- `modules.md`: mapa de modulos.
- `data-model.md`: modelo de datos preliminar.
- `roles-permissions.md`: matriz inicial de roles y permisos.
- `flows.md`: flujos principales.
- `backlog.md`: backlog priorizado.
- `risks.md`: riesgos principales.
- `test-plan.md`: plan de pruebas.
- `project-structure.md`: estructura esperada de carpetas.
- `adr/`: decisiones arquitectonicas.
- `references/`: documentos PDF reales de referencia.
